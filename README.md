# 📻 Radio Cassette — Nostalgia Street Radio

**A retro-inspired music experience built to bring back the feeling of old-school radios, vinyl records, and nostalgic evenings.**

🎧 **Live Demo:** [Listen to Radio Cassette](https://nostalgia-tune-box.lovable.app/)

## ✨ About the Project

Radio Cassette is a music-player web experience inspired by vintage radios, vinyl records, and the nostalgia of listening to music.

The project combines a retro visual aesthetic with an interactive music-player interface to create an immersive listening experience across desktop and mobile devices.

## 🚀 Features

* 🎵 Music player with track information and playback controls
* 💿 Vinyl-inspired visual design and animations
* 📻 Retro-themed interface with a nostalgic atmosphere
* 📱 Responsive experience for desktop and mobile screens
* ⏱️ Live clock displaying Indian Standard Time
* ▶️ YouTube IFrame Player API integration for music playback
* 🎨 Custom visual styling and glass-inspired UI elements

## 🛠️ Technology Stack

The project uses a modern web-development setup. The exact frameworks and dependencies can be verified in `package.json`.

* TypeScript
* React
* Vite
* CSS and utility-first styling
* YouTube IFrame Player API

## 💻 Run Locally

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/CodewithVivekDubey/nostalgia-tune-box.git
```

Move into the project directory:

```bash
cd nostalgia-tune-box
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
